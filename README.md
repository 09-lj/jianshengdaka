# 🔥 炼打卡 · 网页版

一个**纯前端、零后端、零注册**的健身打卡应用。周一三五分化训练 + 周六拉伸，支持训练视频记录与 AI 动作审查。

## 快速体验（本地）

因为用到 `IndexedDB` 和本地文件，需要用一个 HTTP 服务打开（直接双击 `index.html` 也能用，但部分浏览器会限制本地文件权限）：

```bash
# 在项目目录下执行任一命令
python3 -m http.server 8080
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8080`。手机访问用电脑的局域网 IP（如 `http://192.168.1.5:8080`）。

## 🚀 部署到 GitHub Pages（发链接给别人用）

### 方式 A：网页拖拽（不用装任何软件，最省事）

1. 登录 [github.com](https://github.com)，右上角 `+` → **New repository**
2. 仓库名随便起，比如 `fitness`，选 **Public**（私有仓库的 Pages 需要付费），点 **Create repository**
3. 进入仓库，点 **uploading an existing file**
4. 把本项目里**所有文件和文件夹**（`index.html`、`css/`、`js/`、`images/`、`manifest.json`、`README.md`）一起拖进上传区
   - ⚠️ 注意：拖的时候要拖**文件夹本身**（css、js、images），不要只拖里面的文件，否则目录结构会丢
5. 下方点 **Commit changes**
6. 进入仓库 **Settings** → 左侧 **Pages**
7. **Source** 选 `Deploy from a branch`，**Branch** 选 `main` + `/ (root)`，点 **Save**
8. 等 1-2 分钟，刷新该页面，顶部会出现网址：

```
https://你的用户名.github.io/fitness/
```

这个链接发微信、发群里都能直接打开，手机上还能「添加到主屏幕」，用起来和 App 一样（已配置 PWA manifest）。

### 方式 B：命令行（有 git 基础的话）

```bash
cd fitness-web
git init
git add .
git commit -m "init: 炼打卡网页版"
git branch -M main
git remote add origin https://github.com/你的用户名/fitness.git
git push -u origin main
```

推完去 Settings → Pages 打开即可（同上第 6-8 步）。

### 更新代码

改完文件后重新拖拽上传（或 `git push`），Pages 会在 1 分钟左右自动更新。

## 🤖 配置 AI 动作审查

AI 审查需要你自己准备一个**支持图片理解**的大模型 API Key（几块钱能用很久）：

| 服务商 | 获取地址 | 推荐模型 |
|---|---|---|
| 通义千问 | 阿里云百炼控制台 | `qwen-vl-max` |
| 智谱 GLM | 智谱 AI 开放平台 | `glm-4v-plus` |
| Kimi 视觉 | Moonshot 开放平台 | `moonshot-v1-8k-vision-preview` |

配置路径：**我的 → 设置 → AI 动作审查**，填服务商、接口地址、模型名、API Key，点「测试连接」确认可用。

> 🔒 API Key 只存在你自己浏览器的 localStorage，不会上传到任何服务器（除了你直连模型服务商）。
>
> 💡 网页版没有微信小程序的「域名白名单」限制，配好即用。这也是做网页版相比小程序的一大优势。

### 审查原理

1. 抽取视频的 4 个关键帧（15% / 40% / 65% / 88% 时间点），用 canvas 转成 JPEG
2. 把这 4 张图和「该动作的博主发力标准 / 标准节奏 / 常见偏差」一起发给视觉大模型
3. 模型返回结构化报告：动作评分、与博主的发力差异、问题点（带严重度）、改进建议、发力相似度

## 📱 功能清单

- **训练计划**：周一背+腰腹 / 周三胸+肩 / 周五臀+腿 / 周六全身拉伸 / 周二四日休息
- **训练执行**：逐组记录「重量×次数」，自动组间计时（60/90/120 秒），渐进超负荷建议
- **首次训练引导**：新手按「能标准完成 N 次的最后两组略吃力」找基线，之后上肢 +2.5kg / 下肢 +5kg 递进
- **视频打卡**：训练时/训练后拍视频记录，本地 IndexedDB 存储，星标保护 + 一键清理 30 天前，可下载备份
- **AI 动作审查**：对比网络博主的发力标准，指出改进方向
- **打卡激励**：连续打卡（休息日不惩罚自动跳过）、7 枚徽章、月历视图
- **身体数据**：体重折线趋势、体脂记录
- **饮食**：四餐减脂餐推荐（参考健身博主经典搭配）、今日摄入热量/蛋白进度
- **饮水**：每日 8 杯点击打卡

## 💾 数据存储说明

| 数据 | 存储位置 |
|---|---|
| 打卡/训练/身体/饮食/饮水记录、AI 配置 | localStorage |
| 训练视频本体 | IndexedDB |

**全部数据只在这台设备的这个浏览器里**，换设备/清缓存会丢。所以：

- 重要视频请用视频库里的「⬇️ 下载」备份到相册/电脑
- 视频总量超过 1GB 时首页会提醒清理
- 换浏览器或清缓存前，务必先导出

## 🛠 想改点什么

- **改训练动作**：编辑 `js/data.js` 的 `PLAN` 数组
- **改餐单**：编辑 `js/data.js` 的 `MEALS`
- **改配色**：编辑 `css/style.css` 顶部的 `:root` 变量
- **改徽章**：编辑 `js/data.js` 的 `BADGES`

改完直接刷新页面即可看到效果（无需构建步骤，纯原生 HTML/CSS/JS）。
